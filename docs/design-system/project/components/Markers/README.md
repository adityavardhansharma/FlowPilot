Markers are centered one-line events in the feed that aren't messages: compaction, stop, model switch, fork, and time gaps.

## Anatomy
Hairlines in `outline-variant` on both sides, with a centered 18 icon and `label-medium` `on-surface-variant` text.

## Rules
- Time markers appear only when more than 30 minutes separate two turns.
- A marker never has actions, except "Forked from…", which links to the parent chat.
