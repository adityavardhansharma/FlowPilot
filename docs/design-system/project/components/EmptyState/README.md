An empty state says what a place is for and offers the one action that fills it.

## Anatomy
- A 72dp Material shape (Cookie12Sided) in `secondary-container`. It is not an illustration and holds no icon.
- A `title-large` title, a one-line `body-medium` explanation, and one M filled button.
- The error variant swaps the shape tone to `error-container` and adds a text button ("Change computer").

## Rules
- No illustrations, no mascots, no jokes. The copy table in the brand book has every empty message.
- Inbox's empty state has no button, because there's nothing to do. That's the point.
