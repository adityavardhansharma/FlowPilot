The reasoning row folds the model's thinking into one line that can be expanded.

## Anatomy
- A `neurology` icon, then "Thinking · 4s" (shimmering while live) or "Thought for 12s" when done, then a chevron.
- Expanded, it shows the raw reasoning in `body-medium` `on-surface-variant`, indented to the text column. It renders as plain text, not markdown.

## Rules
- Collapsed by default. The setting "Show reasoning" makes it default to expanded.
- The shimmer respects reduced motion (it becomes a static `on-surface-variant`).
- It sits above the answer it belongs to, never inside a work group.
