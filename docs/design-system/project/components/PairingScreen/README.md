The pairing screen connects the app to OpenCode on your computer in one scan.

## Anatomy
- A hero morphing shape (the contained loading indicator, slowed to 6s per cycle), the wordmark in Google Sans Flex 600 with `ROND` 100, and a one-line promise.
- A hint card showing the exact command to run on the computer.
- Thumb-zone actions: **Scan QR code** (M filled, full width) and **Enter address** (M text).

## Flow
See UX flows → First run and pairing. Success morphs the hero into the Cookie12Sided check, then into a Circle.
