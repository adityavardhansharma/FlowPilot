A queued chip is a message waiting to be sent after the current turn, shown above the composer.

## Behavior
- Tap to edit, which moves it back into the composer. Tap × to remove it, with Undo.
- Chips send in order as the agent finishes each turn, each animating up into a user bubble.
- If more than 2 are queued, they collapse to "3 queued" with an expand chevron.
